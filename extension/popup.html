Before you connect

MoneyMinder sends your username and password only to the MoneyMinder server packaged with this extension to authenticate you. It does not store them. It stores the authentication token returned by that server in Chrome so it can load your budget and household data and save expenses you choose to track. The token is sent only to the packaged server.

Optional page processing is separate. It is off by default and requires a separate enable action and Chrome permission. Once enabled, local page processing continues until you disable it, including while logged out. MoneyMinder reads limited order and receipt text locally. Page text is not uploaded; only a purchase you review and choose to Track is sent to the packaged server.
